# Datum Design System

Tokens, variables and components — built in Figma, documented for teams who care about consistency and craft.

Datum is a dark-first design system with a crimson brand accent, blue secondary accent, semantic status colors, and reusable interface components.

## Foundations

- **Color:** primitive palettes and semantic roles for surfaces, text, and borders.
- **Typography:** General Sans for interface text and DM Mono for token names and code.
- **Spacing and radius:** reusable values for layout rhythm and component shape.
- **Elevation:** shadow tokens from subtle separation to prominent overlays.

## Components

The initial library includes Button, Input, Checkbox, Radio Button, Toggle, Tag & Badge, Avatar, Tooltip, and Empty State.

## Using this Storybook

Select a story from the left navigation. Use **Controls** to change supported properties, and switch to the **Docs** tab for API information. Stories are previews; keep production component implementations and token values aligned with the Datum source.
