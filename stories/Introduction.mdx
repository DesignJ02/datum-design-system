## Start with the foundations

- **Color system** — primitive palettes, semantic roles, usage guidance, and copyable values.
- **Typography** — General Sans for interface text and DM Mono for token names and code.
- **Spacing and sizing** — a shared scale for layout rhythm and component density.
- **Radius and elevation** — shape and depth tokens that make components feel related.
- **Components** — interactive examples with controls and implementation references.

## Principles

1. **Use semantic intent in product UI.** Choose a role such as text, surface, border, success, or error instead of picking a random swatch.
2. **Create hierarchy with restraint.** Crimson is for emphasis; neutral surfaces and text should do most of the work.
3. **Design for accessibility.** Validate contrast for the actual foreground/background pair, never assume a brand color is accessible on every surface.
4. **Keep design and code aligned.** Token values shown here are sourced from the current Datum CSS variables; treat the stylesheet as the implementation source of truth.
